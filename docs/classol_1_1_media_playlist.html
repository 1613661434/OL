详细描述

媒体播放列表类，适配 Qt6 QMediaPlayer 实现播放列表管理、自动循环切歌、播放模式控制，无需手动处理音源切换

test_ol_media_playlist.cpp.

◆ PlaybackMode

enum class ol::MediaPlaylist::PlaybackMode : char
strong

播放模式枚举

枚举值
CurrentItemOnce 

当前曲目播放一次后自动停止

CurrentItemLoop 

当前曲目无限循环播放

SequentialLoop 

列表顺序循环，尾首自动衔接
